# Open LLM Battle Agent

Groq API를 활용해 현재 지원되는 여러 LLM에 동일한 질문을 전달하고, 실제 답변 품질과 응답 성능을 비교하여 적합한 모델을 추천하는 AI 에이전트입니다.

---

## 주요 기능

- Groq 계정에서 현재 실행 가능한 텍스트 LLM 조회
- 고정 모델 목록 없이 서로 다른 기업·계열의 모델 자동 선택
- 사용자가 지정한 모델 또는 모델 계열만 선택 가능
- 동일한 질문으로 최대 4개 모델 실행
- 모델별 실제 한국어 답변과 응답 시간 측정
- 관련성, 완성도, 명확성, 실용성, 속도, 안정성 평가
- 모델별 강점·약점과 추천 용도 제공
- 최종 순위와 종합 우승 모델 선정
- 비교 결과를 Markdown 파일로 생성
- Qwen의 내부 추론 내용 제거 및 한국어 답변 검증
- 일부 모델이 실패해도 정상 모델의 비교 작업 계속 진행

---

## 사용 도구

1. `search_groq_llms`
   - Groq에서 현재 실행 가능한 모델을 검색하고 선택합니다.

2. `run_groq_battle`
   - 선택한 모델에 동일한 질문을 전달하고 답변과 응답 시간을 수집합니다.

3. `evaluate_llm_responses`
   - 모델별 답변 품질과 실행 성능을 평가하고 순위를 결정합니다.

4. `generate_report_markdown`
   - 실제 답변과 평가 결과를 Markdown 보고서로 저장합니다.

5. `save_open_llm_report`
   - 모델 검색부터 보고서 저장까지 전체 과정을 한 번에 실행합니다.

### 도구 내부 실행 과정

1. Groq API에서 현재 지원 모델 조회
2. 요청 조건에 맞는 모델 선택
3. 모든 모델에 동일한 질문과 생성 설정 적용
4. 모델별 한국어 답변과 응답 시간 수집
5. 답변 품질과 실행 성능 평가
6. 실제 답변, 평가 결과, 순위를 Markdown 보고서로 저장

---

## 미들웨어 설계

1. `request_safety_middleware`
   - 에이전트 실행 전 빈 입력, 프롬프트 인젝션과 개인정보 입력을 검사하고 위험한 요청을 차단합니다.

2. `workspace_index_middleware`
   - 에이전트 실행 전 Workspace 파일 목록을 확인하여 문서 작업에 필요한 컨텍스트를 제공합니다.

3. `response_pii_masking_middleware`
   - 모델 응답에 포함된 이메일, 전화번호 등 개인정보를 마스킹합니다.

4. `auto_backup_middleware`
   - 파일 수정 도구를 실행하기 전에 원본 파일을 자동으로 백업하고 위험한 파일 작업을 제한합니다.

### 실행 흐름

```text
사용자 요청
→ 입력 보안 검사
→ Workspace 인덱싱
→ 모델 및 도구 실행
→ 응답 개인정보 마스킹
→ 최종 응답
```

## 테스트 질문

### 1. 랜덤 모델 2개 비교

```text
"프롬프트 인젝션이 무엇인지 한 문장으로 설명해줘"라는 질문으로 랜덤 모델 2개를 비교하고 Markdown 보고서로 저장해줘.
```

### 2. 랜덤 모델 4개 비교

```text
"프롬프트 인젝션이 무엇이고 RAG 시스템에서 왜 위험한지 설명해줘"라는 질문으로 랜덤 모델 4개를 비교하고 Markdown 보고서로 저장해줘.
```

### 3. 지정 모델 비교

```text
GPT, Qwen, Groq 모델로 "RAG 문서 오염 공격을 방어하는 방법을 설명해줘"라는 질문에 답하게 하고 비교 결과를 Markdown 보고서로 저장해줘.
```
